## 🎮 Game Hub - Play with Friends!

A fun, interactive game website where you and your friends can play together!

### 🎯 Features

- **User-friendly interface** - Easy login and game selection
- **Multiple Games**:
  - ♻️ **Tic Tac Toe** - Classic strategy game for 2 players
  - 🧠 **Memory Match** - Test your memory with matching cards
  - ✊ **Rock Paper Scissors** - Quick multiplayer competition
  - 🎯 **Number Guesser** - Guess the secret number

### 🚀 How to Play

1. Open `index.html` in your web browser
2. Enter your player name
3. Select a game from the menu
4. Play and have fun!

### 💻 Installation

Simply clone or download this repository and open `index.html` in any modern web browser. No installation or dependencies required!

```bash
git clone https://github.com/henrymelville920-ctrl/hen-10.git
cd hen-10
# Open index.html in your browser
```

### 📁 Files

### 🎮 Game Descriptions

#### Tic Tac Toe
- Classic 3x3 grid game
- Two players: X and O
- First to get 3 in a row wins
- Perfect for turn-based competition

#### Memory Match
- 16 card grid with matching pairs
- Flip cards to find matches
- Score based on number of matches
- Great for memory training

#### Rock Paper Scissors
- Quick rounds of classic game
- Compete against computer
- Score tracking
- Best for quick games

#### Number Guesser
- Computer thinks of a number (1-100)
- You have unlimited guesses
- Get hints (too high/too low)
- Track your attempts
